# موقع وزارة الاقتصاد الرقمي والحوكمة — مشروع متكامل

واجهة مستخدم عامة + لوحة تحكم منفصلة (بدون اعتماديات خارجية، يتطلب Node.js 16 أو أحدث).

## المحتويات
- `index.html` — الواجهة العامة (أخبار، الوزارة، إنجازات، تطلعات، مهام، الهوية البصرية والتصويت، التواصل، الشكاوى).
- `admin.html` — لوحة التحكم. غير مرتبطة بأي زر في الواجهة؛ تُفتح فقط عبر الرابط `/admin.html` (أو `/admin`).
- `server.js` — خادم صغير: حفظ البيانات، رفع الصور والفيديو، كلمة مرور اللوحة، التصويت والشكاوى المشتركة.
- `data/content.js` — المحتوى الابتدائي. `assets/` — الصور والفيديو والتنسيقات والسكربتات.

## التشغيل
```
# Linux / macOS
ADMIN_PASSWORD="كلمة-مرور-قوية" node server.js
# Windows (PowerShell)
$env:ADMIN_PASSWORD="كلمة-مرور-قوية"; node server.js
```
الموقع: http://localhost:3000 — اللوحة: http://localhost:3000/admin.html
المنفذ: متغير `PORT`. كلمة المرور الافتراضية `admin12345` غير آمنة، غيّرها دائماً.

## وضعان
- وضع الخادم (موصى به): كلمة مرور للوحة، حفظ دائم في `data/`، تصويت وشكاوى مشتركة بين الزوار.
- وضع ثابت: فتح `index.html` مباشرة أو رفعه على استضافة ثابتة؛ للعرض فقط، والتعديلات تُحفظ في متصفح صاحبها دون كلمة مرور.

## الثيمات والهوية والتصويت
- 5 ثيمات (زمرد، ليلي، رمل، دجلة، عنابي) من زر الألوان في الترويسة؛ الافتراضي يحدده المدير من الإعدادات.
- 5 مقترحات للشعار والهوية في قسم «الهوية البصرية»: معاينة على الموقع والتصويت. النتائج علنية (أعداد ونسب وسجل مجهول). التصويت استشاري؛ يعتمد الوزير الهوية من اللوحة فتُطبَّق على الموقع.
- صوت واحد لكل زائر (يمكنه تغييره) مع حدّ يومي لكل IP. يمكن إيقاف التصويت أو تصفيره من اللوحة.

## الأخبار والفيديو
من اللوحة: إضافة/تعديل الأخبار، رفع صورة (حتى 8MB) أو فيديو mp4/webm (حتى 25MB). يعمل الفيديو عند الإشارة ويتوقف عند الابتعاد. المتصفحات تمنع الصوت التلقائي قبل تفاعل الزائر مع الصفحة، فيبدأ صامتاً مع تنبيه «انقر لتشغيل الصوت»؛ والنقر على البطاقة يفتحه بالصوت.

## النشر
شغّل الخادم خلف Nginx/Caddy مع HTTPS وفعّل `TRUST_PROXY=1`. الخطوط من Google Fonts (تحتاج إنترنت). أدخل بيانات التواصل والروابط الرسمية من اللوحة، وعطّل شريط «نموذج تصميمي» من الإعدادات عند الإطلاق.
